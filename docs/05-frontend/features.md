# Features Angular

## Dashboard

Muestra:

- USB seleccionada;
- espacio libre;
- último trabajo;
- progreso;
- estadísticas resumidas.

## Downloads

Permite:

- pegar URL;
- analizar;
- seleccionar elementos;
- configurar formato/calidad;
- iniciar;
- pausar;
- cancelar;
- reanudar.

## Storage

Muestra dispositivos detectados y espacio.

## History

Filtra por fecha, fuente, artista, título, estado y dispositivo.

## Settings

Gestiona preferencias de formato, calidad, metadata, portada, carpetas y concurrencia.
