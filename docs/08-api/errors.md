# Errores API

Formato:

```json
{
  "code": "STORAGE_NOT_AVAILABLE",
  "message": "The selected storage device is no longer available.",
  "details": {}
}
```

Códigos iniciales:

- `INVALID_URL`
- `UNSUPPORTED_SOURCE`
- `STORAGE_NOT_AVAILABLE`
- `INSUFFICIENT_SPACE`
- `DUPLICATE`
- `DOWNLOAD_FAILED`
- `PROCESSING_FAILED`
- `VALIDATION_FAILED`
- `JOB_NOT_FOUND`
- `JOB_ALREADY_RUNNING`
- `INVALID_CONFIGURATION`
