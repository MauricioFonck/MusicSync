# Visión del producto

## Problema

El usuario necesita organizar y sincronizar colecciones musicales autorizadas hacia almacenamiento extraíble sin repetir archivos, perder información ante desconexiones ni depender de procesos manuales.

## Solución

MusicSync centraliza:

- análisis de URLs;
- descubrimiento de pistas;
- selección de memoria;
- cola de trabajos;
- descarga;
- procesamiento multimedia;
- metadata;
- detección de duplicados;
- validación;
- historial;
- recuperación ante errores.

## Usuarios

El usuario principal es una persona que administra localmente una colección musical y desea sincronizarla con una o varias memorias USB.

## Visión futura

Convertir MusicSync en una plataforma de gestión local de bibliotecas multimedia con:

- múltiples fuentes;
- múltiples dispositivos;
- perfiles;
- sincronización incremental;
- scheduler;
- aplicación de escritorio;
- NAS;
- estadísticas;
- backups;
- extensiones de fuentes.
