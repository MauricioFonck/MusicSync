# Alcance

## MVP

Incluye:

- Windows 10/11.
- Angular.
- FastAPI.
- SQLite.
- SQLAlchemy/Alembic.
- yt-dlp.
- FFmpeg.
- detección de USB;
- MP3 configurable;
- metadata;
- portada cuando esté disponible;
- organización por artista/álbum;
- historial;
- anti-duplicados;
- cola de trabajos;
- progreso;
- cancelación;
- reanudación básica;
- logs;
- pruebas.

## Segunda fase

- recuperación después de reinicio.
