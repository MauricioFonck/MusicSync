# Documentación de MusicSync

La especificación completa se organiza por áreas:

- `01-product/` — visión, alcance y requisitos.
- `02-architecture/` — arquitectura y decisiones técnicas.
- `03-domain/` — entidades, value objects, eventos y puertos.
- `04-backend/` — backend y casos de uso.
- `05-frontend/` — arquitectura Angular.
- `06-infrastructure/` — motores, FFmpeg, filesystem y USB.
- `07-database/` — modelo y migraciones.
- `08-api/` — contratos HTTP/WebSocket.
- `09-security/` — seguridad y políticas.
- `10-testing/` — estrategia de pruebas.
- `11-devops/` — CI, Docker y releases.
- `12-development/` — convenciones y flujo.
- `13-roadmap/` — plan de implementación.
- `14-claude/` — instrucciones operativas.

La fuente de verdad del proyecto es la documentación versionada en este directorio.
