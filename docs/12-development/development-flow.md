# Flujo de desarrollo

1. Crear issue.
2. Definir criterio de aceptación.
3. Crear branch.
4. Implementar dominio primero.
5. Implementar puertos.
6. Implementar infraestructura.
7. Implementar adapter.
8. Crear tests.
9. Ejecutar lint/typecheck/tests.
10. Actualizar documentación.
11. Pull request.
12. Merge.

No implementar lógica de negocio dentro de controllers.
