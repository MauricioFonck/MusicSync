# Puertos

Interfaces principales:

```python
class DownloaderPort:
    def analyze(self, url): ...
    def download(self, item, destination): ...
    def cancel(self, job_id): ...

class MediaProcessorPort:
    def process(self, source, destination, options): ...
    def inspect(self, path): ...
    def validate(self, path): ...

class StorageDevicePort:
    def list_devices(self): ...
    def subscribe(self, callback): ...

class TrackRepository:
    def find_by_source_id(self, source, source_id): ...
    def save(self, track): ...

class MediaFileRepository:
    def find_by_checksum(self, checksum): ...
    def save(self, media_file): ...

class DownloadJobRepository:
    def get(self, job_id): ...
    def save(self, job): ...
```

Las interfaces pertenecen al núcleo y las implementaciones a infraestructura.
