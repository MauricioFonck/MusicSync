# Eventos de dominio

Eventos:

- `DownloadRequested`
- `DownloadStarted`
- `TrackDownloaded`
- `TrackProcessed`
- `DuplicateDetected`
- `TrackSkipped`
- `DownloadFailed`
- `DownloadCompleted`
- `StorageConnected`
- `StorageDisconnected`

Los eventos permiten desacoplar futuras funcionalidades como estadísticas, notificaciones y auditoría.
